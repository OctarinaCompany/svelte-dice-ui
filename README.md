# svelte-dice-ui

A Svelte port of selected components from [Dice UI](https://diceui.com/docs/introduction),
an unstyled, accessible React component library.

## Status

Early stage — the repository is initialized, no component has been ported yet.

## Goals

- Port a curated subset of Dice UI components to Svelte
- Keep the headless / unstyled approach: behavior and accessibility first, styling left to the consumer
- Stay close to the original API where it makes sense in Svelte
