# Tasks: Tour

**Input**: Design documents from `/specs/032-port-tour/` (plan.md, spec.md, research.md, data-model.md, contracts/tour-api.md, quickstart.md)

**Tests**: Mandatory — Constitution Principle III. Colocated at `src/lib/components/ui/tour/tour.test.ts`, backed by a nested-snippet test harness at `src/lib/components/ui/tour/tour.test.svelte` (this repo's pattern for compound-component tests, per `data-model.md` §3/§6 and `plan.md`'s Project Structure).

**Note on scope divergence** (plan.md research R-02 / R-06, spec.md Assumptions): this port does **not** reuse `scroll-spy`'s `observeSections`/`section-observer.svelte.ts`. `hideWhenDetached` composes `bits-ui`'s `hideWhenDetached` prop (which wraps floating-ui's `hide({ strategy: "referenceHidden" })` middleware) instead of an `IntersectionObserver`, and target-rect tracking is a bespoke `resize`/`scroll`+rAF loop because no existing primitive tracks an arbitrary reference element's rect. `getDefaultScrollBehavior` (the `prefers-reduced-motion` check) is kept as a local 3-line copy, matching upstream's own duplication, rather than an import. These decisions were made and constitution-checked in Phase 1 planning; tasks below follow them rather than the scroll-spy-observer reuse floated before planning.
